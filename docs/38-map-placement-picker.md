# Выбор оборудования из реестра при постановке на карту

## Что изменилось

Раньше клик по карте в режиме «Добавить объект» сразу открывал форму создания нового
объекта. Теперь сначала открывается **лист выбора**:

1. Нажать **«+ Объект»** (или «Разместить» в реестре).
2. Тап/клик по карте в нужной точке.
3. Открывается шторка **«Куда поставить? X … м, Y … м»**:
   * поиск по названию или коду;
   * список объектов реестра: сверху **неразмещённые** («не размещён»),
     ниже — уже стоящие на карте (с координатами);
   * выбор объекта → `PATCH /api/assets/{id}` с координатами точки → объект
     появляется на карте, шторка закрывается.
4. Внизу — **«+ Создать новый объект здесь»**: открывает прежнюю форму создания
   с уже подставленными координатами.

## Файлы

* `src-v2/src/pages/MapPage.tsx` — состояния `placePickerOpen`, `placeQuery`,
  функция `placeExisting`, список `placePickerItems`, шторка выбора.

## Проверки

| Проверка | Итог |
|---|---|
| `tsc --noEmit` / `vite build` | без ошибок |
| Headless-проверка | после клика по карте шторка содержит «Создать новый объект здесь», в списке есть «не размещён» |
| Скриншот | шторка выбора с поиском, неразмещённые сверху, координаты у размещённых |

## Ограничения

1. Список показывает все объекты; фильтра «только неразмещённые» нет (сортировка уже
   поднимает их наверх).
2. Выбор объекта переносит его в точку клика; подтверждения «объект уже стоит,
   перенести?» нет — координаты видны в строке.
3. Групповое размещение (несколько объектов сразу) не поддерживается.
