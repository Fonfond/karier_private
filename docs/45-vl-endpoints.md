# ВЛ от оборудования до оборудования

## Что добавлено

В диалоге **«ВЛ»** на карте появились два поля:

* **«Откуда (оборудование)»** — источник (ПС, КТП, ЯКНО, фидер…);
* **«Куда (оборудование)»** — приёмник.

Поведение:

1. Если выбраны оба объекта — можно **ничего не кликать**: линия пойдёт по прямой
   от источника к приёмнику, опоры встанут равномерно **между ними**
   (без крайних точек, они принадлежат оборудованию).
2. Клики по карте добавляют **изломы трассы** — важные точки. Опоры всё равно
   распределяются автоматически по всей длине ломаной.
3. Связи создаются цепочкой: **источник → опора 1 → … → опора N → приёмник**
   (тип `overhead`, подпись «ВЛ 6 кВ»).

Количество опор задаётся полем «Количество» — вручную указывать каждую не нужно.

## Проверка

| Проверка | Итог |
|---|---|
| `POST /schema/poles/generate` с `source_asset_id` и `target_asset_id`, 4 опоры | 200, 4 опоры, связи источник→опоры→приёмник |
| Граф | 18 узлов, 11 связей (источник, приёмник, 4 опоры, 5 ВЛ-связей) |
| Карта/реестр | опоры появляются сразу после построения |
| `tsc` / `vite build` | без ошибок |
| Тестовые опоры | удалены, остались ваши 9 объектов и 2 связи |

## Ограничения

1. Оборудование выбирается из списка (без поиска и без клика по карте).
2. Если выбрано только «Откуда» (без «Куда»), линия строится до последней указанной
   точки, опоры распределяются внутри.
3. Привязка идёт к портам `OUT` источника и `IN` приёмника; если портов нет —
   они создаются автоматически.
