# Спринт 27: иконки типов, вертикальные порты, связи на карте

## 1. Иконки в редакторе типов

В форме создания/редактирования типа вместо одного текстового поля — сетка из 20 иконок
(промышленная тематика: 🏭 🔌 ⚡ 🔧 ▭ ⏚ 🔁 🏗 ⛏ 🚜 💡 🔻 🪵 📟 🧰 🔋 🚧 ⛽ 🛠 📡)
плюс поле «или введите свой» для произвольного символа. Выбранная иконка подсвечивается.

## 2. Вертикальные порты на схеме

* Каждый узел теперь имеет 8 портов: слева/справа/сверху/снизу, вход и выход
  (`l-in`, `r-in`, `t-in`, `b-in`, `l-out`, `r-out`, `t-out`, `b-out`).
* Сторона связи выбирается по геометрии: если `|dy| ≥ 0.75·|dx|` (блоки стоят друг под другом),
  линия идёт **из низа верхнего блока в верх нижнего**; при обратном порядке — сверху вниз.
  Для блоков в ряд — как раньше, справа налево.
* Порты объектов (перетаскиваемые) сохранены; для связей используется сторона карточки.
* Тип связи — `smoothstep`, поэтому линия ортогональная.

## 3. Связи на карте

* На карте отображаются **все связи** между объектами:
  кабель — зелёный, ВЛ — синий, перемычка — фиолетовый, разомкнутая — пунктир.
* Кнопка **«🔗 Связать»** включает режим: зажать маркер → вести к другому маркеру →
  отпустить. Появляется пунктир-предпросмотр. При отпускании автоматически подбираются
  порты (выход источника → вход приёмника) и открывается форма:
  тип связи, марка, длина, состояние.
* Связь создаётся через существующий `POST /api/links`, поэтому **сразу видна и на карте,
  и на схеме** (общий граф).
* Клик по линии на карте открывает редактор: тип соединения, марка, длина, состояние,
  сохранение (`PATCH /api/links/{id}`) и удаление.
* В режиме «Связать» перетаскивание маркеров отключено, чтобы жест не конфликтовал.

## 6. Ограничения

1. Автоподбор портов берёт первый подходящий; сменить порт у существующей связи через UI
   пока нельзя (только тип/марку/длину/состояние).
2. На карте связь рисуется прямой линией между маркерами, без изломов по рельефу.
3. Иконки — эмодзи; если нужны SVG-иконки, это отдельная итерация.
