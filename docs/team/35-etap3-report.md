## 2. Функциональность

### Связи через ячейки
- у каждой ячейки (вводная/отходящая/секционная) свои Handles `cell:<id>:in/out`;
- линия от внешнего объекта к ячейке создаёт связь по **порту ячейки** (SQL: `BKRU-200:OUT-1 → CELL-315:IN-1`);
- API: block→cell, cell→cell, block→block = 201; архивный порт 422 `link.asset_archived`, чужой 404;
- после перезагрузки связь на месте.

### Размер блока
- угловые маркеры NodeResizer в режиме редактирования, min 160×120; содержимое перестраивается, шапка/секции/подписи целы (`cellsOverflowX=0`, текст не обрезан);
- размер сохраняется в `schema_width/height`; после полной перезагрузки блок открывается ровно того размера (проверено 480×416).

### Перетаскивание ячеек
- ручка ⠿, `extent` по рамкам родителя; координаты в `schema_local_x/y` (проверено 179/66 после reload);
- автосейв без кнопки: debounce 2 с, PUT только изменённого.

### Автосейв и индикация
- **pending → «Сохранение…» (спиннер) → «Все изменения сохранены ✓» (зелёный)**;
- ошибка сети → красная плашка «Ошибка сохранения, проверьте сеть» + автоповтор через 5 с → снова зелёный (проверено: повтор через 5185 мс);
- кнопка «Сохранить раскладку» не обязательна (manualSaveClicks=0).
