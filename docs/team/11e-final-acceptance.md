## 6. Оговорки (не блокируют приёмку кода)

1. **Docker runtime не проверен**: на машине нет Docker, установка Docker Desktop требует прав администратора/UAC. F-1/F-2 приняты статически (81/52 проверки, контексты 0.9 и 1.9 МБ, секретов нет). Нужен прогон `docker compose up -d --build` на машине с Docker — чек-лист в `docs/55-deploy-docker.md` §14.
2. **Полевой прогон** (`docs/56-field-guide.md` §5, 12 пунктов) — требуется телефон/планшет: PWA, авиарежим, фото, синхронизация. Логика сверена с S-5/S-6 и кодом, но живого устройства не было.
3. **I-15** (идемпотентность офлайн-очереди) остаётся в P1: дубли при повторной синхронизации — известное ограничение, описано в инструкции оператора.
4. **`autogenerate`-дрейф**: 29 предсуществующих операций (4 индекса, 2 FK, 23 комментария) — baseline, чистка S-10 после WIP владельца.
5. **HTML5 drag&drop не работает на тач-устройствах** (E-1): на планшете остаётся клик «в центр»/меню; auto-scroll при перетаскивании к краю не реализован.
6. **UI-фильтр по фидеру** не выведен (S-8 — backend-only); в инструкции поля описан API-фильтр.
7. Легаси `backend/` и его `.env` со старым (мёртвым) паролем не тронуты — решение владельца.
