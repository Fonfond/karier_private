## 2. Шапка и холст

### 2.1. Шапка (`AppShell.tsx`)

На `<md` шапка сжата в одну строку (высота **57 px**, было 65): логотип-иконка 32 px + «Карьер»,
переключатель **Карта / Схема** (в шапке, `role=group aria-label="Вид: карта или схема"`,
`aria-pressed`), QR 32×32, синхронизация 32 px (компактная ☁/↑N), профиль `01` — 32×32 (10 px).
Профиль также доступен в нижнем «Ещё» (BottomNav), поэтому уменьшение не отнимает функцию.
Навигация по разделам и «Выйти» на телефоне скрыты (как и раньше), 2FA-бейдж — с `md`.

Переключатель в шапке меняет URL (`/map` ↔ `/map?view=schema`), а `MapPage` теперь следует за
адресом (`useEffect` по `searchParams`), поэтому состояние вида не расходится с URL и работает
переключение из нижней навигации. На десктопе шапка не менялась (одинаковые классы `sm/md`).

Горизонтальный скролл исключён: `html, body { overflow-x: hidden; max-width: 100% }`
(`index.css`); проверено `scrollWidth == innerWidth == 390`.

### 2.2. Панель фильтров над холстом

На телефоне в режиме схемы верхняя панель `MapPage` (вид/фильтры/«N узлов») скрыта
(`hidden md:block` для `view==='schema'`) — переключатель уже в шапке. На карте панель осталась.
На десктопе всё как было.

### 2.3. Холст между шапкой и Bottom Nav

* `MapPage` больше не растягивается под нижнюю навигацию: корень `absolute inset-x-0 top-0`,
  `bottom: var(--bottom-nav-bar)`.
* В `index.css` добавлена фактическая высота панели: `--bottom-nav-bar = 57px + env(safe-area-inset-bottom)`
  (мобильный), `0` на десктопе; `BottomNav` использует ту же переменную для `height` + `env()` —
  холст и панель стыкуются без щели (метрики: canvas 57…787, nav top 787).
* `100dvh`/safe-area: общий каркас `min-h-[100dvh]`, панель учитывает `env(safe-area-inset-bottom)`,
  холст заканчивается над ней; тулбар схемы — `bottom: calc(6px + env(safe-area-inset-bottom))`.
* Интерактивность сохранена и проверена на 390×844: **pan** (transform меняется), **zoom**
  (scale 0.469→0.675), **тап по узлу** (открывается карточка), **перетаскивание ячейки**
  (`left 0→16, top 22→48`), **ресайз блока** (320→420), **автосейв** — «Все изменения сохранены ✓».
  Автосейв этапа 3 не менялся.

## 3. Библиотека блоков — drawer на мобильном

`SchemaView.tsx`:

* на `<md` постоянная панель скрыта (`hidden`); плавающая кнопка **📚**
  (`data-testid="schema-library-open"`, `aria-label="Библиотека блоков"`, `aria-expanded`)
  открывает панель как drawer поверх холста: `absolute left-2 top-12`, ширина 220 px,
  `max-h-[60%]`, заголовок с кнопкой ✕ и `data-testid="schema-library-panel"`;
* затемнение `data-testid="schema-library-backdrop"` (z-30) закрывает drawer по тапу вне;
* выбор блока закрывает drawer: `onClick={() => { setLibraryOpen(false); void placeBlock(block.code) }}`
  (на мобильном тап = поставить блок в центр холста);
* drag&drop карточек (десктоп) сохранён;
* `≥768px` — прежняя постоянная панель 196 px, кнопка 📚 и backdrop скрыты (`md:hidden`);
  проверено: `panel width=196`, `openBtnVisible=0`, подпись «Библиотека блоков» на месте.

## 4. Компактная панель управления схемой (мобильный)

`SchemaView.tsx`, отдельная мобильная панель `data-testid="schema-mobile-toolbar"`
(`md:hidden`), на десктопе её нет — там прежний широкий тулбар с переносом строк.

* Прижата к низу холста: `bottom: calc(6px + env(safe-area-inset-bottom))`, высота **54 px**,
  `flex-nowrap`, ширина 374 px (rect `x=8..382`, `bottom=781` при холсте до 787) — центр холста
  не перекрывает.
* Состав в один ряд: переключатель режима редактирования **без текста** — квадрат 32×32 с иконкой
  (`👁` / `✏️`) и `aria-label="Режим редактирования"`; «+ Добавить» (primary); «▤ По шаблону»;
  «⋯ Ещё».
* «Ещё» (`data-testid="schema-more-open"`) открывает лист `schema-more-sheet`: Снимки,
  Сохранить раскладку, Авто-раскладка, Ячейки, Кабель, Линия, № опор, Отменить/Повторить,
  Шаблон ГОСТ, Перемычка, Легенда, DXF, Рамка, Двигать порты — вся функциональность доступна
  без широкой панели.
* `+ Добавить` и `По шаблону` оставлены и на десктопе; мобильная копия кнопки шаблона имеет
  отдельный `data-testid="schema-composite-open-mobile"`, чтобы не дублировать селектор.
* Safe-area учтён во всех нижних элементах: тулбар, лист «Ещё», BottomNav.

## 5. Тосты (ошибки, статусы, подсказки)

* Статус и ошибка схемы теперь единый компактный тост `data-testid="schema-toast"`:
  на мобильном — сверху по центру (`top-2`, `w-max`, `max-w[calc(100%-16px)]`, 11 px),
  `pointer-events: none`, `role=status/alert`; на десктопе — прежняя плашка справа сверху
  (`md:right-2`, `md:pointer-events-auto`, 12 px).
* Автоскрытие на телефоне — **5 с** (статус, ошибка, `dangerHint`, drag-подсказка), на десктопе
  прежние 8/7/6 с (логика десктопа не менялась). Проверено: тост исчез через ~5.4 с.
* Тост не сдвигает вёрстку (абсолютное позиционирование) и не блокирует жесты (`pointer-events:none`);
  drag-подсказка тоже `pointer-events-none`, уменьшена на мобильном (`bottom-16`, 11 px).
* Индикатор автосейва (`schema-autosave`) на мобильном компактнее (11 px, max-width), логика
  сохранения/повтора не менялась.

## 11. Замечания и границы

* «До» снято с уже развёрнутой web-сборки Docker-стека; «После» — с нового `dist`, API тот же.
  База — demo `karier_db` стека; созданные для сценария блоки `UI5-*` удалены после съёмки.
* Выбор блока закрывает drawer (код `onClick` закрывает до `placeBlock`); автотест проверяет
  закрытие тапом вне и `aria-expanded` — выбор блока не автоматизирован, чтобы не создавать
  дополнительные объекты в demo-базе.
* Drag-подсказка (HTML5 drag библиотеки) актуальна в основном для десктопа; на телефоне блок
  ставится тапом из drawer. Таймер подсказки на мобильном уменьшен до 5 с, `pointer-events:none`.
* Тост может кратко перекрыть верхние узлы холста (он абсолютный, `pointer-events:none`,
  автоскрытие 5 с) — это компромисс «не сдвигать вёрстку»; интерактивность под ним доступна.
* `--bottom-nav-bar` (57 px) синхронизирован с высотой `BottomNav`; при изменении высоты панели
  менять обе переменные в `index.css` и `BottomNav.tsx`.
