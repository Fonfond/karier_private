### 1.2 Что критично (по убыванию риска)

1. **Обход RBAC на `POST /api/sync/push`** — без `asset.create` можно менять `status`/`grounded`/координаты, `move` и вставка дефекта идут вообще без прав (`B-01`). Для системы, где эти поля означают электробезопасность, — blocker.
2. **Реальный пароль `karier_user` в отслеживаемом файле** `tests/conftest.py:24` + публичный `origin` (`R1`): push = утечка к рабочей БД. Тот же пароль — в `config.py:27`, `smoke.ps1`, `docs/52`. **Пока не ротирован/вычищен — не пушить.**
3. **OTP-код в ответе `/auth/register/start` и в логах/stdout** на стенде (`B-02`): зная табельный номер, можно задать сотруднику пароль.
4. **Секреты в дефолтах**: пароль БД и dev-`SECRET_KEY` в `config.py:26-34`, слабые seed-пароли, `must_change` не принудителен (`B-06`).
5. **Офлайн не работает на холодном старте** (`F-01`, blocker фронтенда) и **service worker отдаёт данные одного сотрудника другому** на общем планшете (`F-03`).
6. **Утечки и обходы границ**: доверие `X-Forwarded-For` → обход лимитов входа/MFA и подделка IP в аудите (`B-03`); SVG inline без CSP → хранимый XSS (`B-04`); подложка карты без аутентификации и с публичным кэшем (`B-05`).
7. **Гигиена репозитория блокирует выпуск**: 207 МБ битого venv без `.gitignore` (`R2`), 194 файла CRLF маскируют 19 реальных правок (`R3`), git не установлен (`R33`).
8. **Ломающее изменение контракта 422**: ключи `fields` стали русскими подписями (`R5`); мёртвый `assert` в `test_schema_builder.py:93` (`R4`).
9. **5,19 МБ sourcemap (68 % `dist`) публично доступны** (`F-02`/`I-12`).
10. **Нет CI, изоляции тестов, тестов миграций и метрик покрытия** — «162 passed» не защищает ни миграции, ни права (`Q-1…Q-4`).
