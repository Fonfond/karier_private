# JSON-схема v2 по эскизу (karier.sketch/v1, version 2.0)

Исправлена по замечаниям главного энергетика (ПУЭ гл. 1.5, 3.2, 4.2).

Файлы:
* `backend-v2/seed_data/sketch_v2.json` — канонический JSON;
* `docs/sketches/sketch-v2.json` — копия;
* `backend-v2/seed_demo_sketch.py` — построение схемы в БД (метка `attrs.demo = sketch_v2`);
* `backend-v2/gen_sketch_json.py` — выгрузка JSON;
* `backend-v2/import_sketch_json.py` — импорт JSON (`--dry-run`, `--clean`).

## Топология

```
Т-1 35/6 ─┐
          ├─ ПС 35/6 «Карьер»: I секция (яч.1–15) / II секция (яч.16–30), СВ на границе
Т-2 35/6 ─┘
   ф.7к  → оп.1 → оп.2 → оп.3 → оп.4 → Реклоузер → КТП №4 (400 кВА) → Л-1/Л-2 0.4 кВ
                          └─ отпайка → ЯКНО-1/1к → Ввод 2 БКРУ-1
   ф.16к → ЯКНО-6 (6 ячеек, ЭКГ-12К/1, ЭКГ-12К/2, ЭКГ-15М)
   ф.21к → Ввод 1 БКРУ-1
   БКРУ-1: 2 секции + СВ, фидеры ф.2 / ф.3 / ф.5 → ПКТП-3, ЭКГ-15М, ПКТП-4
```

## Что исправлено относительно v1

| Замечание энергетика | Исправление в v2 |
|---|---|
| БКРУ односекционное, ввод 2 висит | 2 секции + СВ, IN-1 от ф.21к, IN-2 от ф.7к через ЯКНО-1/1к |
| ЯКНО-1 тупик, питание перевёрнуто | ЯКНО-1/1к стоит на отпайке оп.4 → ввод 2 БКРУ; тупиков нет |
| Ф.16к/ф.21к перепутаны | ф.16к → ЯКНО-6, ф.21к → БКРУ ввод 1, ф.5 — фидер БКРУ |
| Нет источника 35 кВ | добавлены Т-1/Т-2 35/6 кВ, вводы ПС подписаны «от Т-1/Т-2» |
| Нет QF/QS/ТТ/ОПН/учёта | на каждом фидере ПС: QF VD4 630A + ТТ 600/5 0.5S + ОПН + Wh; в БКРУ QF+ТТ+ОПН; КТП: QS+QF+ТТ+ОПН, ТР 400 кВА, QF 0.4 кВ |
| СВ «яч. 8/23», ввод 2 в яч.16 | СВ на границе яч. 15/16, ввод 1 — яч. 2, ввод 2 — яч. 17 |
| Реклоузер у ПС на кабеле | Реклоузер после оп.4, на ВЛ перед КТП |
| Опоры 14/13/12, в обратном порядке | оп.1 → оп.2 → оп.3 → оп.4 (от ПС к КТП), отпайка с оп.4 |
| Нет нагрузок | ЭКГ-15М 1500 кВт, ПКТП-1 63 кВА, ПКТП-2 630 кВА, ПКТП-3 400 кВА, ПКТП-4 400 кВА |
| КТП 250 кВА без аппаратов | ТР 400 кВА, вводной QS+QF+ТТ+ОПН, QF на каждой линии 0.4 кВ |
| Все связи cable, длины 120 м | ВЛ — `overhead` (СИП-3), кабель — `cable`; длины 30…280 м по участкам |
| Разные имена фидеров ПС и БКРУ | ПС: ф.7к/ф.16к/ф.21к; БКРУ: ф.2/ф.3/ф.5 |

## Состав JSON v2

* 17 блоков: 2 источника 35/6, ПС, 4 опоры, реклоузер, КТП, ЯКНО-1/1к, ЯКНО-6, БКРУ-1, 5 нагрузок;
* 17 связей, `dangling_ports: []`;
* у блоков в `params` — секции, вводы, СВ, фидеры с `qf`, `ct`, `meter`, `opn`, `cable`, `power_kw`;
* `canvas.units = "layout_px"` (координаты — пиксели раскладки, не метры).

## Остаётся уточнить у энергетика

1. Марки СБ на ф.7к: в v2 принято СБ-3×95 (как в замечании), на ВЛ — СИП-3 3×120/3×70.
2. Резервные линии КТП Л-3/Л-4 и ячейки ЯКНО-6 №4–6 помечены «резерв».
3. Заземляющие ножи показаны на секциях ПС (ЗН I/II) и в реклоузере; на каждой ячейке
   отдельные ЗН не выводились, чтобы не перегружать карточку.
