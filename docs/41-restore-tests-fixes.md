## 2. Связи на карте

Причины, почему не создавались:

1. У объектов, созданных без шаблона портов, **не было портов** — форма связи падала
   на «нет подходящих портов».
2. После переключения кнопки на режим «Связать» соединение работало только
   перетаскиванием; клик по двум объектам ничего не делал.

Исправлено:

* Новый эндпоинт `POST /api/assets/{id}/ports/ensure` — создаёт `IN-1`/`OUT-1`,
  если портов нет.
* При попытке связи карта сама вызывает `ensure` для обоих объектов и повторяет выбор портов.
* Клик-соединение: первый клик по маркеру — источник, второй клик по другому — форма связи
  (перетаскивание тоже работает).
* Проверено: `POST /api/links` с валидными портами → **201**, связь появляется на карте и схеме;
  при разных напряжениях сервер отвечает 422 `link.voltage_mismatch` — но Smart Connect
  не даёт такую связь создать (подсветка + блокировка).

## 3. PDF-паспорт

Эндпоинт существует: `POST /api/reports/token` с `{kind:"passport", asset_id}` возвращает
короткоживущую ссылку на PDF. Проверено: `200`, ссылка формируется.

В контекстное меню узла добавлен пункт **«⬇ Скачать паспорт (PDF)»** — открывает PDF
в новой вкладке.

## 4. Undo/Redo

Пока покрывает **только перемещение узлов** (история позиций). Отмена создания/удаления
связей, объектов и ячеек **не реализована**: для этого нужен снимок графа и обратные
операции на сервере (создание связи с теми же портами, восстановление удалённого объекта),
это отдельная задача на 0,5–1 день. Не стал делать полурабочий вариант перед защитой.
