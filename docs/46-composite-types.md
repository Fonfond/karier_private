# Комплектное оборудование (БКРУ-1, ПС 35-6)

## Как настроить

1. «Типы» → открыть `БКРУ-1`.
2. Включить **«Комплектное оборудование»** — «одно оборудование с ячейками».
3. В списке подтипов указать количество каждой ячейки (по умолчанию 1) и сохранить.

Тип запоминает состав: `is_composite` + `composite_template`
(`[{type_code, count, label}]`). Так же можно настроить `ПС 35-6`.

## Как поставить на карту

1. На карте — кнопка **«Комплект»**.
2. Выбрать тип (`БКРУ-1`) → «Указать место» → клик по карте.

Результат:

* создаётся **один объект** (родитель) с координатами — на карте одна иконка;
* создаются дочерние ячейки (`яч №1…яч №6`) с `schema_block_id` родителя;
* на схеме комплект рисуется **рамкой с ячейками** (тем же рендерером, что и блоки);
* в реестре виден родитель, ячейки — при включённом «вложенные»;
* у родителя есть порты `IN-1` / `OUT-1` — к нему можно тянуть связи.

## API

* `PATCH /api/asset-types/{id}` — `is_composite`, `composite_template`.
* `POST /api/composites/place` — `{type_id, x, y, name?}` → родитель + ячейки.
* `POST /api/composites/{parent_id}/attach` — `{child_ids:[…]}` — добавить
  существующие объекты (например, ваши текущие ячейки ПС) в комплект.

## Проверка

| Проверка | Итог |
|---|---|
| Тип `БКРУ-1` | `is_composite=true`, 6 позиций состава |
| Размещение | 200, создано 6 ячеек, родитель `БКРУ-1` |
| Граф | блок с 6 `children`; узлы — родитель, ячейки внутри рамки |
| `tsc` / `vite build` | без ошибок |
| Тестовые объекты | удалены, остались ваши 9 объектов |

## Ограничения

1. Присоединить уже существующие ячейки к комплекту можно пока через API
   (`attach`); кнопки в интерфейсе нет.
2. Внутренние связи/шины между ячейками не создаются автоматически — рамка и состав есть,
   связи добавляются вручную.
3. Названия ячеек берутся из подтипов; при количестве >1 добавляется номер.
