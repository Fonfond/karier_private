# ВЛ: ломаная трасса и локальная перенумерация

## 1. Ломаная трасса ВЛ

Кнопка **«ВЛ»** → параметры → **«Указать точки»**. Дальше:

* клик по схеме добавляет точку, линия тянется за курсором (пунктирное превью);
* **Enter** или кнопка **«Завершить линию»** — построить ВЛ;
* **Esc** или «✕» — отменить.

Опоры распределяются равномерно **по всей длине ломаной** (не по прямой между крайними точками):
считается длина каждого сегмента, точки ставятся по накопленному расстоянию.
Связи ВЛ создаются последовательно между соседними опорами, повторяя изломы.

API: `POST /api/schema/poles/generate` с полем `path: [[x,y], …]`
(старые `x1..y2` сохранены для совместимости).

## 2. Локальная перенумерация

Кнопка **«№»** → по умолчанию выбран режим **«только выбранная линия»**:

1. «Указать опору» → клик по любой опоре нужной линии;
2. задать начальный номер, шаг, префикс;
3. «Перенумеровать» — меняются только опоры этой цепочки.

Цепочка ищется по связям `overhead` между опорами: от выбранной опоры алгоритм
идёт к концу линии, затем проходит её целиком и нумерует по порядку.
Опоры других линий не затрагиваются.

Второй режим — «все опоры на схеме» (как раньше), с подтверждением.

API: `POST /api/schema/poles/renumber-chain`
(`anchor_asset_id` или `link_id`, `start`, `step`, `prefix`).

## 3. Ответвление к потребителю

У опор, созданных генератором, есть порты **IN-1** и **OUT-1**. Поэтому от опоры
можно штатно протянуть связь к КТП/ЯКНО (в режиме «Соединить» или с карты).
Специального инструмента не потребовалось.

## 4. Эксклюзивность инструментов

* Включение **«ВЛ»** сбрасывает режим перемычки и незавершённую линию.
* Включение **«Перемычка»** отменяет набор точек ВЛ.
* Завершение/отмена линии очищает состояние.

## Ограничения

1. Двойной клик не завершает линию (используются Enter и кнопка) — так надёжнее
   на тач-устройствах.
2. Перенумерация цепочки работает для **линейной** линии; если линия ветвится
   (несколько цепочек от одной опоры), берётся первый путь.
3. Выбор линии — по опоре, выбор по связи ВЛ пока не делается.
