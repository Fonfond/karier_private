возьмём из Visio и из ваших правок после первой итерации.

## 2. Чем текущая схема отличается от референса

| Сейчас | В референсе |
|---|---|
| Прямоугольники с кодом и типом | Условные обозначения: выключатель, разъединитель, ТТ, ОПН, ТСН, заземление, секции шин |
| Связи — линии с подписью | Линии по ГОСТ 2.303-68, подписи марок кабелей и длин вдоль линии |
| Нет шин как отдельной сущности | Горизонтальные шины `1С 6 кВ` / `2С 6 кВ`, ячейки ответвляются вниз |
| Нет рамки и штампа | Лист с рамкой, штампом, согласованием, масштабом |
| Нет нумерации ячеек | Номера ячеек (7, 21, …), нумерация опор ВЛ |
| Статусы цветом | Печатный стиль: чёрные линии, цвет только для оперативных состояний |

## 3. Предлагаемый план (4 этапа)

### Этап 1. Символы и оформление узлов (2–3 дня)

* `gis.asset_types.schema_symbol` (enum: `breaker`, `disconnector`, `ct`, `arrester`,
  `transformer`, `busbar`, `line`, `load`, `generator`, `ground`) — задаётся в админке типов.
* Компонент `SymbolNode` в React Flow: рисует ГОСТ-символ + подпись (`В-6`, `ТТ1.1`),
  порты остаются перетаскиваемыми.
* Автоподбор символа по типу объекта; для 27 существующих объектов — миграция значений.

### Этап 2. Шины, секции и шаблоны листов (2 дня)

* Узел-шина: горизонтальная линия с названием секции (`1С 6 кВ`) и произвольной длиной.
* Привязка ячеек к шине: `gis.assets.schema_bus_id` (или связь через порты) + авто-выравнивание по вертикали.
* Шаблоны раскладки: «Ввод 35/6 кВ», «БКРУ-1», «Фидер ВЛ» — кнопка в редакторе,
  раскладывает выбранный набор объектов по образцу референса.

### Этап 3. Рамка и штамп (1–2 дня)

* SVG-рамка листа (A3/A1) с полями: организация, объект, лист, масштаб, «Разработал /
  Проверил / Утвердил», дата.
* Настройки штампа в админке (текстовые поля), хранение в `gis.pits.attrs` или отдельной таблице.
* Рамка входит в PDF/DXF-экспорт; на экране — опционально (тумблер «Показать рамку»).

### Этап 4. Экспорт и печать (1–2 дня)

* DXF: слои `BUSBARS`, `CELLS`, `LINKS`, `LABELS`, `FRAME`; типы линий по ГОСТ 2.303-68.
* PDF: лист со штампом, рамкой и легендой (уже есть reportlab).
* Проверка: открыть результат в nanoCAD (у вас установлен) и сравнить с референсом.

**Итого:** 6–9 рабочих дней, без изменения текущей логики питания и MCP.

## 4. Что нужно от вас

1. Подтвердить объём: все 4 этапа или только 1–2 (символы и шины) для начала.
2. Прислать один лист из Visio в PDF/PNG как эталон оформления (или сказать,
   что page5 достаточно) — чтобы совпали пропорции и штамп.
3. Уточнить формат листа: A3 горизонтальный (как обычно для однолинейных) или A1.
4. Если нужна точная геометрия из DWG — экспортируйте его в DXF из nanoCAD
   (`Сохранить как → DXF`), тогда я разберу слои и повторю компоновку.

## 5. Риски

* ГОСТ-символы в React Flow — это SVG-компоненты, а не библиотека; на 10–12 символов
  уйдёт примерно день, зато без внешних зависимостей.
* Штамп и рамка требуют согласования текстов (организация, подписанты) — их лучше
  вынести в настройки, чтобы менять без релиза.
* DWG без конвертера не читается: если геометрия критична, нужен экспорт в DXF.
