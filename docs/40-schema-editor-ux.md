# UX редактора схем: Smart Connect, направляющие, меню, Undo/Redo

## 1. Smart Connect (главное)

* При начале протяжки от порта все **совместимые входы подсвечиваются** зелёным
  с пульсацией; несовместимые — гаснут (opacity 20%).
* Совместимость: целевой порт — вход (`in`/`io`), напряжение совпадает
  (если у порта оно не задано — допускается).
* `isValidConnection` в React Flow **блокирует неверные соединения ещё до отправки**:
  OUT→OUT, OUT→вход с другим напряжением, сам на себя. Курсор «запрещено», дроп не
  создаёт связь — 422 от сервера больше не возникает на этом пути.
* Подсказки портов: «Ввод IN-1 · 6 кВ», «Отходящая OUT-1 · 0.4 кВ».
* Серверная валидация и разрешение реальных UUID портов (фикс 422) сохранены —
  Smart Connect лишь не даёт дойти до ошибки.

## 2. Трассировка линий (частично)

* Связи по-прежнему ортогональные (`smoothstep`, радиус скругления 8), сторона
  выбирается по геометрии (столбец — низ→верх, ряд — справа налево).
* **Обход препятствий не реализован**: для настоящего A*-роутинга нужен отдельный
  edge-компонент (или пакет `react-flow-smart-edge`) и расчёт препятствий по bbox узлов.
  Это следующий шаг, текущая ортогональная трассировка остаётся.

## 3. Направляющие (Smart Guides)

* При перетаскивании узла сравниваются центры с другими узлами (допуск 8 px).
* При совпадении по X или Y рисуется **синяя пунктирная линия** через всю схему
  (через `ViewportPortal`, в координатах схемы).
* Линии исчезают после отпускания.

## 4. Контекстное меню (правый клик)

| Объект | Действия |
|---|---|
| Узел | «Открыть карточку», «Свернуть/развернуть» (для блоков), «Удалить» |
| Связь | «Редактировать связь», «Сделать перемычкой», «Удалить» |
| Пустое место | «Авто-раскладка», «Отменить», «Повторить» |

Меню закрывается по клику на пустом месте.

## 5. Undo / Redo

* Кнопки **↩** и **↪** в панели редактора.
* История хранит **позиции узлов** (перетаскивание), до 100 шагов; сохраняется
  в памяти сессии (не в БД).
* После отмены/повтора раскладка помечается изменённой — нужно нажать
  «Сохранить раскладку», чтобы записать в БД.

## О тестах

Полный `pytest` **не прогонялся**: после «чистого листа» база не содержит сидов,
на которых построены 144 теста (типы, объекты, связи). Это не связано с изменениями
редактора: изменён только фронтенд (`SchemaView.tsx`), бэкенд не трогался.
Чтобы прогнать suite, нужно восстановить демо-дамп (`backups/karier_before_clean_20261109.dump`)
или выполнить `seed.py` — оба варианта перезапишут текущие данные. Скажите, если делать.

## Ограничения

1. Обход препятствий линиями — не сделан (см. п. 2).
2. Undo/Redo не покрывает создание/удаление связей и узлов — только перемещения.
3. «Скачать паспорт» из меню заменено на «Открыть карточку»: отдельного PDF-паспорта
   по объекту в API нет (есть общий экспорт отчётов).
4. «Вставить из буфера» в меню пустого места не реализовано.
