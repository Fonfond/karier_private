# Построение линии: пачки ячеек, кабели, оборудование и цвета питания — отчёт

Версия 1.0 · 24.11.2026 · миграций не потребовалось (голова `0014_schema_snapshots`)

## 1. Задача

Собрать схему линии целиком: контур ПС → пачка ячеек со сквозной нумерацией и
секциями → кабель от ячейки к опоре → КТП/ЯКУ/разъединитель в линии → наглядная
индикация «под напряжением / отключено». Всё созданное должно сразу попадать в
реестр (`gis.assets`) и связи (`gis.links`), с отменой и повтором.

## 2. Что сделано

### 2.1 Пакетные ячейки со сквозной нумерацией и секциями

`POST /api/schema/assets/{id}/cells/bulk`:

| Параметр | Смысл |
|---|---|
| `count` | сколько ячеек (1…200) |
| `start` | стартовый номер (сквозная нумерация) |
| `prefix` / `suffix` | формат имени: `Яч. №{n}` |
| `section_size` | ячеек в секции (0 — без секций) |
| `section_prefix` | подпись секции (`Секция 1`, `Секция 2`…) |
| `role`, `type_code` | роль и тип ячейки |

Каждая ячейка — объект `gis.assets` с `parent_id` блока, `schema_block_id`,
`attrs.sequence_no` и `attrs.section` / `attrs.section_no`. Ответ содержит
`items` (id/код/имя) и список секций.

В редакторе кнопка «＋» в шапке блока открывает диалог «Ячейки пачкой»: количество,
стартовый номер, префикс/суффикс, размер секции, роль. Секции рисуются
разделителями внутри блока (`Секция 1`, `Секция 2`).

Отмена: удаление всех созданных ячеек; повтор: восстановление из архива.

### 2.2 Отходящий кабель от ячейки к опоре/оборудованию

`POST /api/schema/assets/{asset_id}/cables` — принимает `to_asset_id`, марку,
длину, сечение, жилы. Порты подбираются автоматически: у источника — выход/двунаправленный,
у приёмника — вход/двунаправленный; если портов нет, создаются `IN-1`/`OUT-1`
(существующие проверки напряжения и направления остаются в силе).

В редакторе — режим «Кабель»: клик по ячейке, затем по опоре/КТП/разъединителю,
ввод марки. Связь создаётся с `cable_mark` и попадает в `GIS.links`.

### 2.3 Оборудование линии (КТП, ЯКУ, разъединители)

`POST /api/schema/line-equipment` — создаёт объект выбранного типа в реестре,
ставит его рядом с опорой на схеме (`schema_x/schema_y`) и соединяет кабелем
с опорой. В панели «+ Добавить» появилась вкладка «Оборудование линии»: поиск
опоры/узла, выбор типа (по умолчанию подставляется КТП/ЯКУ/разъединитель),
название и марка кабеля.

### 2.4 Цветовая индикация питания

В редакторе схемы:

* **красный** — объект под напряжением или включён (`energized` или статус `on`);
* **зелёный** — отключено / без питания (остальные статусы);
* связи: включённая — красная, разомкнутая — зелёная пунктиром; перемычка —
  красная/зелёная с коротким пунктиром.

Палитра вынесена в `POWER_COLOR` (`src-v2/src/lib/gis.ts`), обновлена легенда
под схемой.

## 5. Ограничения

1. Секции — только метки и визуальные разделители; отдельного объекта «секция»
   с шинами в реестре не создаётся (шины — через библиотеку блоков).
2. Кабель от ячейки к опоре не рисует трассу: связь идёт по кратчайшему пути
   (геометрия трассы — отдельная задача).
3. Явный выбор типа ячейки в диалоге не выводится — используется тип `cell`
   с запасным подбором активного аналога.
4. Оборудование линии ставится рядом с опорой; точное положение пользователь
   поправляет перетаскиванием.
5. В рабочей `karier_db` на момент отчёта есть контур «ПС 35-6 кВ» (`PS_35-3`),
   созданный 24.11 в 10:27 — он не создавался этим прогоном (браузерные проверки
   шли на тестовой БД) и оставлен как пользовательские данные.
