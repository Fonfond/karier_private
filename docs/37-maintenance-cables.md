# Журнал ТО и кабельный журнал (этапы 2–3)

Миграция: `0012_maintenance_cables`.

## 1. Журнал ТО (мачты, генераторы, мобильная техника)

**Тип:** в редакторе типа появился флаг **«Журнал ТО»** — «вести моточасы, топливо и ТО».

**Карточка объекта:** для таких типов появляется вкладка **«ТО»**:
* текущие моточасы и уровень топлива (из последней записи);
* форма: тип записи (ТО / заправка / ремонт / прочее), моточасы, топливо %, заправлено л, примечание;
* история записей с датами.

**API:**
* `GET /api/assets/{id}/maintenance` — список записей;
* `POST /api/assets/{id}/maintenance` — добавить (admin), пишет `attrs.motor_hours` и `attrs.fuel_level_pct`;
* `DELETE /api/maintenance/{id}` — удалить (admin).

Таблица `ops.maintenance_entries`: `at`, `kind`, `motor_hours`, `fuel_liters`, `fuel_level_pct`, `cost`, `note`, `author_id`.

## 2. Кабельный журнал

**Поля связи** (миграция): `cable_no` (номер кабеля), `cable_status`
(`in_work` / `reserve` / `repair` / `dismounted`), `installed_on` (на чём установлен),
`route_note` (примечание).

**Страница «Кабели»** (`/cables`, пункт в верхнем меню и в «Ещё» на телефоне):
* таблица: № кабеля, марка, тип (кабель/ВЛ/шина/перемычка), статус, длина,
  откуда → куда, «установлен на»;
* поиск по номеру/марке/объектам, фильтр по статусу;
* клик по строке — редактор: номер, марка, статус, длина, место установки, примечание.

Те же поля добавлены в редактор связи на карте (тип, марка, № кабеля, статус, установлен на, длина, состояние).

## 3. Проверки

| Проверка | Итог |
|---|---|
| Миграция 0012 | применена |
| Флаг `has_maintenance` | PATCH типа → `true` |
| Запись ТО | `POST` → `201`, список → 1 запись |
| Поля кабеля | `PATCH /api/links/{id}` → `cable_no=КЛ-17`, `cable_status=reserve` |
| `tsc --noEmit` / `vite build` | без ошибок |
| Тестовые данные | удалены, остались только ваши 3 объекта и 5 типов |

## 4. Ограничения

1. Напоминаний «пора на ТО» по порогу моточасов пока нет — только ручной ввод и история.
2. В кабельном журнале показываются все связи, включая перемычки и шины (тип выводится колонкой).
3. Экспорт журнала в Excel не добавлен.
4. Удаление записи ТО есть в API, но кнопки в интерфейсе нет (сделаем вместе с напоминаниями).
5. Разъединение группы ПС — по-прежнему через API (`/asset-groups/{id}/ungroup`).
