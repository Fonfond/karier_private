# Построение ВЛ с карты

## Что изменилось

Кнопка **«ВЛ»** теперь на **карте** (рядом со «Связать»), а не в редакторе схемы.

Порядок:

1. «ВЛ» → диалог: количество опор, начальный номер, шаг, префикс.
2. «Указать точки» → клики по карте задают точки трассы (ломаная).
3. **Enter** или кнопка **«Завершить»** (внизу) — построение; **Esc**/«✕» — отмена.

Что происходит после построения:

* создаются объекты-опоры с координатами на карте (`schema_x/y`);
* между соседними опорами создаются связи `overhead` («ВЛ 6 кВ»);
* опоры сразу появляются **на карте**, в **реестре** и **на схеме** (узлы + связи,
  схема строится по сохранённым координатам);
* список объектов обновляется без перезагрузки страницы.

Пока линия строится, на карте виден пунктирный предпросмотр трассы.

## Файлы

* `src-v2/src/pages/MapPage.tsx` — режим ВЛ, диалог, клики, Enter, завершение, refresh.
* `src-v2/src/components/map/MapView.tsx` — предпросмотр ломаной (`vlPath`).
* `src-v2/src/components/map/SchemaView.tsx` — кнопка «ВЛ» убрана; перенумерация «№» осталась
  (это операция над схемой).

## Проверки

| Проверка | Итог |
|---|---|
| UI: «ВЛ» → диалог → 3 точки → «Завершить» | сообщение «ВЛ построена: 5 опор», опоры `оп.1…оп.5` |
| Реестр | 14 объектов: ваши 9 + 5 созданных |
| Граф схемы | 14 узлов, 6 связей — опоры и ВЛ на схеме |
| `tsc` / `vite build` | без ошибок |
| Тестовые опоры | удалены, остались ваши 9 объектов |

## Ограничения

1. Нумерация опор при построении с карты — общая (префикс/шаг), локальная
   перенумерация цепочки осталась на схеме.
2. Линия строится по кликам без «привязки» к существующим объектам.
